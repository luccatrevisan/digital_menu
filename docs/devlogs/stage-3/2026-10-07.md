```javascript
async function confirmOrder() {
    const addressId = getSelectedAddressId(); // function to get the address selected by the user
    const warning = document.getElementById("order-warning");

    if (addressId === null) {
        warning.hidden = false;
        warning.textContent = "Selecione um endereço de entrega.";
        return;
    }

    const payload = {
        address_id: addressId,
        items: getCart().map(item => ({
            menu_item_id: item.id,
            quantity: item.quantity
        }))
    };

    const accessToken = localStorage.getItem("access");
    if (!accessToken) {
        window.location.href = "/login/";
        return;
    }

    confirmOrderButton.disabled = true;

    try {
        const response = await fetch("/api/orders/", {
            method: "POST",
            headers: {
                "Content-Type": "application/json",
                "Authorization": `Bearer ${accessToken}`
            },
            body: JSON.stringify(payload)
        });

        if (response.status === 401) {
            localStorage.removeItem("access");
            localStorage.removeItem("refresh");

            window.location.href = "/login/";
            return;
        }

        if (!response.ok) {
            let error = null;

            try {
                error = await response.json();
            } catch (e) {
                console.error("Non-JSON response:", e);
            }

            warning.hidden = false;

            if (!error) {
                warning.textContent = "Erro no servidor. Tente novamente em instantes.";
            }
            else if (error.code === "minimum_order") {
                warning.textContent = "O pedido precisa ultrapassar o limite de R$30,00.";
            }
            else if (error.items?.code === "empty_cart") {
                warning.textContent = "O carrinho não pode ser concluído sem itens.";
            }
            else if (error.items?.code === "item_unavailable") {
                warning.textContent = `O item ${error.items.menu_item} não está disponível no momento.`;
            }
            else if (error.items?.code === "item_does_not_exist") {
                warning.textContent = "Esse item não existe.";
            }
            else if (error.items?.code === "stock_unavailable") {
                warning.textContent = `O item ${error.items.menu_item} não tem estoque o suficiente. Disponíveis: ${error.items.remaining}`;
            }
            else if (error.address_id) {
                warning.textContent = "Endereço inválido. Selecione outro endereço.";
            }
            else {
                warning.textContent = "Não foi possível concluir o pedido. Tente novamente.";
            }

            return;
        }

        const data = await response.json();
        cleanCart();
        window.location.href = `/orders/success/?order=${data.order_id}`;

    } catch (error) {
        console.error(error);
        warning.hidden = false;
        warning.textContent = "Erro ao conectar com o servidor.";

    } finally {
        confirmOrderButton.disabled = false;
    }
}
```

### Key Decisions
- **Create the order after address selection:** Both the cart items and delivery address are needed to create a complete order.
- **Send one order POST:** The cart button is navigation only; checkout confirmation submits one request containing `address_id` and `items`.
- **Validate address ownership on the server:** A client-provided address ID is not trusted; it must belong to the authenticated user.
- **Keep transactional creation in the service:** Address association, stock changes, item creation, and order validation remain part of the service's transaction.
- **Separate UI navigation from API calls:** After order creation was removed from the cart's `checkout()` function, it only checks authentication and navigates. It belongs beside the cart button listener in `script.js`; `apiCalls.js` remains responsible for address API operations.
- **Keep the cart in localStorage:** The `chewie_cart` key lets the cart survive page reloads. It is cleared only after a successful order response.

### Challenges
1. **Two order-creation requests in one checkout**
   - **What happened:** The initial flow created the order when the user clicked the cart modal's checkout button. The new flow also created an order after address selection on the checkout page, so one checkout could send two `POST /api/orders/` requests.
   - **How I solved it:** The cart button now only navigates to checkout. The order is created once, after the user confirms the selected delivery address.
   - **What I learned:** Separate navigation from order creation, and submit only after all required details are available.

2. **Preserving authentication while removing the duplicate request**
   - **What happened:** The cart's original order POST also performed an authentication check. Removing that POST removed its login redirect along with the duplicate order creation.
   - **How I solved it:** Preserved the missing-token redirect in the cart navigation function. Address loading and final order submission also clear stale access/refresh tokens and redirect when the server returns `401`.
   - **What I learned:** When removing a request, identify and preserve required side effects instead of removing the entire flow blindly.
  
3. **Cart appeared empty after reloading the home page**
   - **What happened:** The cart uses `localStorage` under `chewie_cart`. Browser checks showed that storage persisted across reloads at `http://127.0.0.1:8000/`; a temporary cart entry restored the badge quantity after reload. `localhost` and `127.0.0.1` are different origins and do not share localStorage.
   - **How I solved it:** Traced the storage key and all save/clear paths rather than replacing localStorage. Removed the stale `window.checkout = checkout` export from `apiCalls.js`, which raised a `ReferenceError` after `checkout()` moved to `script.js`. Also guarded checkout-summary initialization because those elements do not exist on the home page.
   - **What I learned:** Verify the current origin and storage key, inspect all code that writes or clears the cart, and check runtime errors before assuming browser storage is at fault.
