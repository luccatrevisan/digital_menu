<script>
    const STORAGE_KEY = "chewie_cart";

    function renderOrderSummary() {
        console.log("renderOrderSummary");
        const cart = JSON.parse(localStorage.getItem(STORAGE_KEY)) || [];
        console.log(cart);

        const orderSummary = document.getElementById("order-summary");
        const cartTotal = document.getElementById("cart-total");

        orderSummary.innerHTML = "";

        let total = 0;

        cart.forEach(item => {

            const subtotal = item.price * item.quantity;
            total += subtotal;

            orderSummary.innerHTML += `
                <div class="order-item">

                    <strong>${item.name}</strong>

                    <p>
                        ${item.quantity} × R$ ${item.price.toFixed(2)}
                    </p>

                    <p>
                        Subtotal:
                        <strong>R$ ${subtotal.toFixed(2)}</strong>
                    </p>

                </div>

                <hr>
            `;
        });

        cartTotal.textContent = `R$ ${total.toFixed(2)}`;
    }

    document.addEventListener("DOMContentLoaded", () => {

function addToCart(id, name, price, image){
    const existingItem = cart.find(item => item.id === id);
    
    if (existingItem) {
        existingItem.quantity += 1;
    } else {

### Key Decisions
- **Why I chose to not allow users to change their order in the checkout page:**
    Because the checkout page would unnecessarily complex. The main goal right now is to get real users to place their order on this project and this feature would be a waste of time right now. But, to keep a good UX, I placed a button ("Voltar ao cardápio") to send the user back to the main menu (index) to help the user change their order. Its not a bad solution since the cart is still intact after coming back from the checkout page.

### Challenges
1. The cart was going empty to the checkout page.
   - **How I solved it:** Used console.log(cart) - since the cart logic is on javascript - to check how exactly the cart is arriving on the html.
   - **What I learned:** It was empty because I decided to clear the cart after the user clicked on the Checkout button. Inittially I chose this because the checkout button on the cart-modal was responsible to confirm the order. Since I decided now to use another page to confirm the items, select an address and then finish the order, emptying the cart doesn't make sense - at this particular point of the flow.
